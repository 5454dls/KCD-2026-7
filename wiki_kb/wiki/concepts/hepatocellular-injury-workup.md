# 간세포형 손상(AST/ALT 상승) 평가

## 첫 단계
- 평가 전에 검사를 반복하거나 확인 검사를 해서 실제로 이상인지 확인합니다 (ACG 2017 p.2, p.10).
- 병력에는 간질환 위험인자, 동반 질환, 음주, 일반약과 한약 보충제를 포함한 약물 사용을 넣고, 진찰로 만성 간질환 징후와 특정 원인 징후를 찾습니다 (ACG 2017 p.9).
- 혈액질환 병력이 있는 환자는 간정맥 혈전으로 급성 우상복부 통증, 복수, 간비대를 보일 수 있습니다 (ACG 2017 p.10).
- 심부전 병력(울혈성 간병증), 조기 폐기종, 셀리악병, 갑상선질환도 간 외 원인으로 확인합니다 (ACG 2017 p.10). [[congestive-hepatopathy]]

## 상승 정도별 평가 (권고 16-19, Figure 1-3)
### 경계(<2X ULN)와 경도(2-5X ULN): Figure 1
- 병력·진찰, 간독성 약물 중단, 금주, 지방간·바이러스 간염 위험인자 평가로 시작합니다 (ACG 2017 p.10).
- CBC/혈소판, AST/ALT, ALP, 총빌리루빈, 알부민, PT/INR, HBsAg, HBcAb, HBsAb, HCV Ab(양성이면 PCR 확인), 철 검사, 복부 초음파를 시행합니다 (ACG 2017 p.10).
- 음성이면 경계 상승은 3-6개월, 경도 상승은 3개월 관찰 후 재검하거나 평가를 계속합니다 (ACG 2017 p.10).
- 지속 상승 시 ANA, ASMA, 감마글로불린, 세룰로플라스민, A1AT 표현형을 검사하고, 병력에 따라 셀리악, 진드기 매개 질환, 갑상선, 근육 질환 검사를 추가할 수 있습니다 (ACG 2017 p.10).
- 경도 상승에서 진단이 안 되면 진단적 간생검을 고려합니다 (ACG 2017 p.10).
- 권고 16: ALT/AST <5X ULN이면 B·C형간염, 알코올·NAFLD, 혈색소증, 윌슨병, A1AT 결핍, 자가면역간염을 평가하고 약물·보충제 손상을 고려합니다 (ACG 2017 p.2).

### 중등도(5-15X ULN): Figure 2
- 권고 17: <5X ULN의 모든 원인에 더해 급성 A·B·C형간염을 평가합니다 (ACG 2017 p.2).
- 간독성 약물과 알코올을 중단하고 급성 간부전 징후를 평가합니다 (ACG 2017 p.11).
- 검사는 CBC/혈소판, AST/ALT, ALP, 총빌리루빈, 알부민, PT/INR, HAV IgM, HAV IgG, HBsAg, HBcAb IgM, HBcAb IgG, HBsAb, HCV Ab(양성이면 PCR 확인), 철 검사, 세룰로플라스민, ANA, SMA, 감마글로불린, 복부 초음파입니다 (ACG 2017 p.11).
- 급성 간부전 징후가 있으면 긴급 간 협진과 간이식센터 의뢰를 고려하고, 검사가 음성이면 의학적으로 안정된 경우 진단적 간생검을 고려합니다 (ACG 2017 p.11).

### 중증(>15X ULN)과 대량(ALT >10,000 U/L): Figure 3
- 권고 18: >15X ULN 또는 ALT >10,000 IU/l이면 아세트아미노펜 독성과 허혈성 간병증(shock liver)도 평가합니다 (ACG 2017 p.2). [[hypoxic-hepatitis]]
- 중증 상승에서는 간독성 약물·알코올 중단과 급성 간부전 징후 평가를, 대량 상승에서는 여기에 독성 섭취, 허혈, 횡문근융해 평가를 더합니다 (ACG 2017 p.12).
- 검사는 CBC/혈소판, AST/ALT, ALP, 총빌리루빈, 알부민, PT/INR, HAV IgM, HBsAg, HBcAb IgM, HBsAb, HCV Ab, HSV, EBV, CMV, 세룰로플라스민, ANA, ASMA, Anti-LKM, IgG, 혈청 약물 검사, 소변 독성 검사, Doppler 복부 초음파입니다 (ACG 2017 p.12).
- 아세트아미노펜 복용 증거가 있으면 N-acetylcysteine을 고려합니다 (ACG 2017 p.12).
- 권고 19: 급성 간염에 PT 연장 그리고/또는 뇌병증이 있으면 즉시 간 전문의에게 의뢰합니다 (ACG 2017 p.2).
- 급성 간부전은 기존 간질환이 없는 환자에서 PT 연장과 간성 뇌병증으로 나타나는 합성 기능의 심한 장애가 빠르게 생기는 것으로 정의하며, ALT 수치와 무관하게 즉시 평가합니다 (ACG 2017 p.12).

## 상승 정도별 원인
- 경계·경도 상승은 Table 4의 다양한 간·비간 원인에서 보입니다 (ACG 2017 p.12).
- 중증 상승은 급성 바이러스 간염, 허혈성 간염/shock liver, 패혈성 쇼크, 급성 Budd-Chiari·급성 간동맥 폐색 같은 혈관질환, 독소·약물 유발 간손상, 자가면역간염, 급성 담도폐쇄, 암의 미만성 간 침윤, 간 외상·수술, VOD/SOS, HELLP, 윌슨병에서 생길 수 있습니다 (ACG 2017 p.12).
- 간 관련 원인으로 >10,000 U/l까지 오르는 대량 상승은 대체로 shock liver/허혈성 간병증 또는 약물·독성 간염에서만 보입니다 (ACG 2017 p.12).
- 횡문근융해와 열사병 같은 비간성 질환도 중증·대량 AST 상승을 일으킬 수 있습니다 (ACG 2017 p.12).
- 아미노전이효소가 가장 높게 오르는 경우는 대개 아세트아미노펜 과량, 허혈성 간병증, Amanita phalloides 같은 독소 노출입니다 (ACG 2017 p.12, p.13).
- 중등도 이상 상승에서는 급성 A·B·C·D·E형간염, 만성 B형간염의 급성 재활성화, HSV·EBV·CMV 같은 비간친화성 바이러스 간염, 급성 자가면역 간질환, 특이체질 약물 반응, 직접 간독소(아세트아미노펜)를 평가합니다 (ACG 2017 p.12).
- 혈액 악성종양과 최근 항암치료 병력은 SOS(VOD)를, 과응고 상태에서의 간 검사 이상과 복수는 Budd-Chiari 증후군을 시사합니다 (ACG 2017 p.13).

## Table 4 원인 목록 요약
- 간 원인 중 대체로 AST>ALT: 알코올 간질환, 간경변, 허혈성 간염, 울혈성 간병증, 급성 Budd-Chiari 증후군, 간동맥 손상·혈전·폐색, TPN (ACG 2017 p.9).
- 간 원인 중 대체로 ALT>AST: NAFLD(지방증, NASH), 만성·급성 바이러스 간염, 약물·DILI(처방약, 한약·보충제, 일반약), 독성 간염(amanita), 혈색소증, 자가면역간염, 윌슨병, A1AT 결핍, 셀리악병, 급성 담관 폐쇄, 간 외상, 간 수술 후, VOD/SOS, 암의 미만성 간 침윤, HELLP, 임신 급성 지방간, 패혈증, HLH (ACG 2017 p.9).
- 비간 원인: 골격근 손상·횡문근융해, 심근 손상, 갑상선질환, macro-AST, 격렬한 운동, 열사병, 용혈, 부신기능부전 (ACG 2017 p.9).

## 약물·보충제 간손상(DILI)
- 처방약, 일반약, 비처방 보완대체요법과 식이 보충제는 급성·만성 간손상의 흔한 원인입니다 (ACG 2017 p.8). [[dili-diagnosis-and-causality]]
- 원인 약물을 찾기 어려우므로 환자와 가족에게 자세히 묻고 의무·약국 기록과 검사 자료를 꼼꼼히 검토해야 합니다 (ACG 2017 p.8).
- 거의 모든 약물이 ALT/AST/ALP나 빌리루빈을 조금이라도 올릴 위험이 있습니다 (ACG 2017 p.8).
- 흔한 원인 약물군은 항생제, 항경련제, NSAID, 스타틴, 항결핵제, HIV 항레트로바이러스제, 항-TNF 같은 생물학제제, 일부 항암제입니다 (ACG 2017 p.8).
- 스타틴은 ALT·AST 상승과 연관되지만 만성 간질환에서도 안전성 문헌이 많고 간독성 보고는 드뭅니다 (ACG 2017 p.8).
- ALT >1,000 IU/l이면 단독 또는 진통·마약성 복합제 형태의 아세트아미노펜 복용력을 정확히 확인하는 것이 필수입니다 (ACG 2017 p.8).
- 특정 약물로 귀속하려면 흔히 중단 후 간 검사의 완전 회복을 관찰하는 경험적 시도가 필요하며, 약이 꼭 필요하면 대체약을 찾거나 면밀한 감시 계획을 세웁니다 (ACG 2017 p.8). [[dili-management-and-rechallenge]]
- 급성 또는 중증 전격성 간염에서는 손상 정도 확인과 원인 약물 진단을 위해 간생검이 필요할 수 있습니다 (ACG 2017 p.8).
- 간독성 한약 보충제로 chaparral, ephedra, ji bu huan, germander, 녹차 추출물, 상어 연골을 들고, 확인 자료로 livertox.nih.gov를 소개합니다 (ACG 2017 p.8). [[herbal-dietary-supplement-injury]]

## 기타 원인별 검사 (간세포형 감별)
- NAFLD: 대사증후군 특징과 경도 ALT 상승이 있으면 초음파로 선별하며, 대개 ALT>AST이고 300 IU/l을 넘는 경우는 드뭅니다 (ACG 2017 p.2, p.6).
- 알코올: 의미 있는 음주는 남성 주 >210 g, 여성 주 >140 g이며, AST:ALT ≥2:1이고 AST·ALT가 300 IU/l을 넘는 일은 드뭅니다 (ACG 2017 p.7).
- 자가면역간염: ANA, ASMA, 드물게 anti-LKM 또는 anti-SLA, 고감마글로불린혈증이 시사 소견이며 확진에는 간생검이 필요합니다 (ACG 2017 p.7).
- 혈색소증: 트랜스페린 포화도 ≥45% 또는 페리틴 상승 시 HFE 분석을 고려하지만, 페리틴은 급성기 반응물이라 급성 간염에서의 상승은 철 과부하를 뜻하지 않을 가능성이 큽니다 (ACG 2017 p.7).
- 윌슨병: 세룰로플라스민으로 선별하고 낮으면 24시간 소변 구리 그리고/또는 혈청 구리, 세극등 검사를 시행합니다 (ACG 2017 p.8).
- A1AT 결핍: 정량 수치와 PiZZ 유전형 검사로 선별합니다 (ACG 2017 p.8).
- 근육 질환: 다른 흔한 원인을 배제한 뒤 CK 그리고/또는 aldolase로 선별을 고려합니다 (ACG 2017 p.9).
- 갑상선질환: TSH로 시작해 선택적으로 free T4, free/total T3를 검사합니다 (ACG 2017 p.9).

## ICU 원인 판단에 쓰는 법
(아래는 원문 내용을 ICU 상황에 적용한 파생 해석입니다.)
- ALT/AST >15X ULN 또는 >10,000 IU/l이면 권고 18에 따라 허혈성 간병증(shock liver)과 아세트아미노펜·약물 독성을 반드시 평가 목록에 올리는 근거가 됩니다 (ACG 2017 p.2, p.12).
- 패혈성 쇼크는 원문에서 중증 AST/ALT 상승 원인으로 명시되어 있어, 쇼크 상태 환자의 중증 상승에서 패혈증과 허혈을 함께 고려하는 근거가 됩니다 (ACG 2017 p.12).
- 대량 AST 상승에서는 횡문근융해와 열사병 같은 비간 원인을 CK 등으로 배제하는 단계가 원문 알고리즘에 포함되어 있습니다 (ACG 2017 p.9, p.12).
- 원인 약물 귀속은 투약 기록 검토와 중단 후 회복 관찰을 기반으로 하며, 이는 DILI 0/1 판단에서 노출 확인 단계에 해당합니다 (ACG 2017 p.8).
- 원문 알고리즘은 외래 관찰(3-6개월)을 전제로 하는 부분이 많아, ICU에서는 중등도 이상 경로(즉시 평가)를 주로 적용하게 됩니다 (ACG 2017 p.10, p.12).

## 근거 공백
- 허혈성 간염의 진단 기준(혈역학적 사건, 시간 경과, LDH 등)은 원문에 없습니다. [[hypoxic-hepatitis]] 참고.
- 울혈성 간병증과 허혈성 간염을 구별하는 방법은 다루지 않습니다.
- DILI 인과성 평가 도구(RUCAM 등)와 잠복기 기준은 원문에 없습니다. [[dili-diagnosis-and-causality]] 참고.
- 패혈증에서 AST/ALT 상승 기전이나 진단 기준은 다루지 않습니다.
- ICU 흔한 약물(진정제, 항진균제 등)별 위험이나 다약제 환자의 귀속 방법은 없습니다.
