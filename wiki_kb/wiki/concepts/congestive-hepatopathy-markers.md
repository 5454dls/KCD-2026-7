# 울혈성 간병증의 표지자 (Lemmer 2017 Table 1 중심)

울혈성 간병증의 개념과 HH와의 관계는 [[congestive-hepatopathy]]에 있습니다. 이 페이지는 진단·병기 결정에 쓰이는 표지자가 원문에서 어떻게 평가되는지만 모읍니다. 주 출처 [[lemmer-2017-congestive-hepatopathy]]는 Fontan 코호트 자료를 바탕으로 한 만성 울혈 리뷰입니다(Lemmer 2017 p.1, p.3).

## 정의 (원문)

- 울혈성 간병증(만성 수동 간정맥 울혈)은 우심부전과 기타 심장 결손으로 간정맥압이 만성적으로 높아져 생깁니다(Lemmer 2017 p.1, p.4).
- 비염증성 과정이며, 초기 증상은 합성 기능이 보존된 상태의 문맥압 항진에서 옵니다(Lemmer 2017 p.1).

## 혈청 검사 (Table 1, Fontan 코호트 평균과 범위)

| 검사 | 평균 (범위) | 원문의 임상 유용성 평가 |
|---|---|---|
| AST | 31.3 (6-159) | 제한적 |
| ALT | 28.6 (6-170) | 제한적 |
| ALP | 89.8 (7-467) | 제한적 |
| 빌리루빈 | 0.83 (0.1-4.8) | 제한적 |
| INR | 1.19 (0.91-1.77) | 제한적 |
| 알부민 | 4.43 (1.5-5.5) | 제한적 |
| 혈소판 | 171 (29-659) | 낮으면 문맥압 항진 악화 시사 |
| GGT | 72.2 (5-922) | 높으면 문맥압 항진 악화 시사 |
| FibroSURE | 0.44 (0.11-0.85), 참고치 <0.21 | 제한적 |
| Hyaluronic acid | 26 (7-277), 참고치 <46 | 제한적 |
| MELD | 보고 없음 | 울혈성 간질환에서 위험 추정 근거 없음 |
| MELD-XI | 보고 없음 | 생검 섬유화 병기와 상관, 임상 결과 예측에 중등도 근거 |

(Lemmer 2017 p.3) 단위는 표에 적혀 있지 않습니다.

- 대부분의 표준 간 검사는 말기 직전까지 정상에 가깝고 섬유화 등급과 상관하지 않습니다(Lemmer 2017 p.1-2).
- 낮은 혈소판과 높은 GGT는 섬유화가 아니라 문맥압 항진 정도와 상관하므로, 심기능과 우심 압력의 표지로 봅니다(Lemmer 2017 p.2). [[gamma-glutamyl-transferase]]

## BNP와 NT-proBNP

- BNP는 한 리뷰에서 생검 섬유화 등급과 상관하지 않았습니다(Lemmer 2017 p.2).
- 울혈성 간병증에서 BNP와 임상 결과의 관계는 따로 연구되지 않았고, 비울혈성 간경변에서 BNP 상승이 간기능 이상 단계·사망과 상관한다는 근거가 있다는 정도만 언급합니다(Lemmer 2017 p.2).
- NT-proBNP는 이 원문에 나오지 않으며, 울혈성 간병증 진단을 위한 BNP 또는 NT-proBNP 역치는 제시되지 않습니다(Lemmer 2017 p.1-4).

## MELD와 MELD-XI

- MELD는 INR이 말기에만 오르고 상당수가 만성 항응고 중이라 울혈성 간병증의 중증도와 대상부전 위험 추정에 효과가 없어 보입니다(Lemmer 2017 p.2).
- INR을 뺀 MELD-XI는 여러 연구에서 간 대상부전과 사망을 예측했고, 심장이식 또는 심간 동시이식 후보 결정에 쓰일 수 있으나 그 용도의 검증 연구는 없습니다(Lemmer 2017 p.2).
- 요약은 MELD-XI를 임상 결과를 예측하는 유일한 검증된 혈청 기반 검사로 정리합니다(Lemmer 2017 p.4).

## 영상과 탄성도

- 초음파: 대개 간비대와, 울혈로 인한 하대정맥·간정맥 확장, 문맥압 측정치 증가를 보입니다(Lemmer 2017 p.2). 문맥계 압력과 흐름 평가에 가장 유용합니다(Lemmer 2017 p.3).
- CT·MRI: 간비대와 결절 모양이 흔하고, 약 30%에서 국소 결절성 과형성(FNH)을 닮은 과증강 결절이 보이며 간세포암과 구별이 어려울 수 있습니다(Lemmer 2017 p.3).
- 결절 윤곽이 항상 말기 섬유화를 뜻하지는 않으며, 결절 모양 간을 가진 환자 다수가 심장이식 후 지속적인 간기능 이상이 없었습니다(Lemmer 2017 p.3).
- 순간 탄성도, ARFI, MR 탄성도(MRE)는 간내 혈액량 증가와 부종 때문에 모두 일관되게 높게 나와, 울혈과 섬유화를 구별하는 데 유용성이 제한됩니다(Lemmer 2017 p.4).

## 조직

- 굴모양혈관 주위 부종, 중심정맥 주위 세포 주위 섬유화, 염증 없는 간세포 위축이 보이고, 진행하면 중심-중심, 중심-문맥 가교 섬유화와 재생 결절이 생깁니다(Lemmer 2017 p.3-4).
- 간세포 사멸이 위축과 세포자멸사로 일어나 현미경적 염증은 미미합니다(Lemmer 2017 p.4).

## 혈역학 표지 (다른 원문)

- EASL 2017은 HH 일부에서 좌우 심기능 이상이 있으면 간정맥 배출을 위해 우심 압력을 최소화하라고 하지만 수치 목표는 주지 않습니다(EASL ALF 2017 p.13).
- EASL 2017은 향후 과제로 간 울혈과 용적 고갈을 평가하는 바이오마커를 듭니다(EASL ALF 2017 p.14).
- HH 리뷰는 중심정맥압 상승을 HH 환자에서 확인된 소견으로 들지만 역치는 없습니다(HH review p.2). [[waseem-chen-hypoxic-hepatitis-review]]

## ICU 원인 판단에 쓰는 법

(아래는 원문에서 도출한 적용 방법이며 원문의 직접 권고가 아닙니다.)
- Fontan 코호트에서 만성 울혈의 간 검사는 평균값이 정상 범위에 가깝습니다(Lemmer 2017 p.3). 따라서 ICU에서 ≥2×ULN의 새 간 검사 이상을 만성 울혈만으로 설명할 근거는 이 원문에서 얻기 어렵고, 급성 저관류가 겹친 HH를 함께 고려하는 것이 원문들과 맞습니다(HH review p.2, EASL ALF 2017 p.5).
- GGT 상승과 혈소판 감소는 울혈 자체보다 문맥압 항진·우심 압력을 반영하는 보조 소견으로만 씁니다(Lemmer 2017 p.2).

## 근거 공백

- 울혈성 간병증의 진단 기준(점수나 필수 소견 조합)은 이 원문에도 없으며, 원문은 근거 기반 지침이 없다고 명시합니다(Lemmer 2017 p.4).
- NT-proBNP와 BNP의 역치, 중심정맥압이나 간정맥압의 역치가 없습니다.
- ICU의 급성 울혈(급성 우심부전, 기계환기 중 고PEEP 등)에서 간 검사 패턴을 다룬 자료가 없습니다.
