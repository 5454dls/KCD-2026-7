# 급성 간부전(ALF)의 정의, 하위 분류, 원인 평가

## 정의

| 용어 | 정의 (EASL 2017) | 쪽 |
|---|---|---|
| 급성 간부전 (ALF) | 기저 만성 간질환 없이 간 검사의 급성 이상, 간 원인의 응고장애, 간성 뇌병증(HE)에 의한 의식 변화가 모두 있음 | p.1 |
| 급성 간손상 (ALI) | 응고장애는 있으나 의식 변화가 없음 | p.1 |
| 중증 ALI | 아미노전이효소 상승(손상 표지)과 간기능 저하(황달, INR >1.5), 대개 뇌병증에 앞섬 | p.1, p.3 |
| 만성 간부전의 급성 악화 (AoCLF) | 만성 간질환 환자의 급성 악화. ALF와 구별 | p.1 |
| 이차성 간손상 | 일차 간 손상 없이 전신 질환에서 응고장애·효소 상승·빌리루빈 이상·의식 변화가 보이는 경우. ALF가 아님 | p.1 |

- ALF를 정의하는 응고 이상은 대개 INR >1.5 또는 PT 연장입니다(EASL ALF 2017 p.2). 황달과 HE는 임상적으로 나타나야 하며, 초기 정신 변화는 미묘할 수 있어 적극적으로 찾아야 합니다(EASL ALF 2017 p.2).
- 중증 ALI의 시작은 아미노전이효소 2-3배 상승과 황달·응고장애로 기술됩니다(EASL ALF 2017 p.1).
- 예외: 자가면역 간염, Wilson병, Budd-Chiari 증후군의 급성 발현은 기저 간질환이 있더라도 HE가 생기면 ALF로 봅니다(근거 II-2, 권고 1) (EASL ALF 2017 p.3).
- 광범위 간절제 후 small-for-size 유사 증후군은 ALF 범위 밖이고, 외상은 정맥·동맥 유입이 모두 소실된 경우가 아니면 ALF 원인이 아닙니다(EASL ALF 2017 p.1).

## 하위 분류 (황달부터 HE까지 간격)

| 체계 | 분류 | 쪽 |
|---|---|---|
| O'Grady 1993 | 초급성(hyperacute) 7일 이내, 급성(acute) 8-28일, 아급성(subacute) 5-12주 | p.2, p.4 |
| IASL 1999 | 초급성 10일 미만, 전격성(fulminant) 10-30일, 아급성 5-24주 | p.2 |
| 원래 정의 (Trey, Davidson 1970) | 첫 증상 후 8주 이내 뇌병증 발생 | p.2 |

- 뇌병증 전 유병 기간이 28주를 넘으면 만성 간질환으로 분류합니다(EASL ALF 2017 p.2).
- 초급성은 심한 응고장애, 현저한 효소 상승, 초기에는 경미한 빌리루빈 상승을 보이고 자연 회복 가능성이 큽니다(EASL ALF 2017 p.2).
- 아급성은 효소 상승이 덜하고 황달이 깊으며, 비장비대, 복수, 간 용적 감소가 있어 간경변으로 오인되기 쉽고, HE가 생기면 자연 생존 가능성이 매우 낮습니다(EASL ALF 2017 p.2, p.4).
- 원문은 아미노전이효소 수치가 진단에 완전히 믿을 만한 지표는 아니라고 덧붙입니다(EASL ALF 2017 p.2).

## 원인과 응급 이식 적응 (Table 2, Table 5)

| 군 | 원인 | 쪽 |
|---|---|---|
| 일차 간 원인 (응급 이식이 치료 선택지일 수 있음) | 약물, 급성 바이러스 간염, 독소, Budd-Chiari, 자가면역, 임신 관련 | p.6 |
| 간외·이차성 (응급 이식이 치료 선택지 아님) | 허혈성 간염(HH), 혈구탐식 증후군, 대사 질환, 침윤성 질환, 림프종, 감염(예: 말라리아) | p.6 |

- 유럽 원인 분포(Table 3)는 나라마다 크게 달라, 영국은 paracetamol 43%, 미국 39%이고, 인도는 바이러스 68%입니다(EASL ALF 2017 p.5).
- 전 세계적으로는 바이러스(A, E, B형)가 여전히 가장 흔한 원인이고, 유럽에서는 DILI가 가장 흔합니다(EASL ALF 2017 p.3).

## 원인별 임상 특징 (Table 6과 본문)

| 원인 | 특징 | 쪽 |
|---|---|---|
| 급성 허혈성 손상 | 아미노전이효소 현저 상승, LDH·크레아티닌 증가, 혈역학 안정 후 빠른 정상화, 심한 울혈성 심질환 또는 호흡기 질환. AST 흔히 >10,000 IU/L이고 ALT의 두 배 이상, 첫 빌리루빈 정상 흔함 | p.5-6 |
| Paracetamol | 매우 높은 아미노전이효소(대개 >10,000 IU/L), 낮은 빌리루빈, 빠른 진행, 산증, 신기능 저하 | p.6 |
| 비 paracetamol 약물 | 효소 상승이 덜하고 빌리루빈이 더 높으며 혼합형·담즙정체형이 흔함. 아급성 경과는 간경변과 비슷해 보일 수 있음 | p.6-7 |
| 악성 침윤 | 암 병력, 거대 간비대, ALP·GGT 상승. 림프종은 LDH가 아미노전이효소보다 더 많이 오름 | p.5-6 |
| 급성 Budd-Chiari | 복통, 복수, 간비대, 초음파에서 간정맥 신호 소실·문맥 역류 | p.6 |
| Wilson병 | 젊은 환자, Coombs 음성 용혈성 빈혈, 높은 빌리루빈 대 ALP 비, Kayser-Fleischer 고리, 낮은 요산, 소변 구리 현저 증가 | p.6, p.8 |
| 버섯 중독 | 섭취 후 심한 위장관 증상, 조기 급성 신손상 | p.6, p.8 |
| 자가면역 | 대개 아급성, 자가항체 양성, 글로불린 상승. 없을 수도 있음 | p.6-8 |

## 원인 평가 권고

- 약물: 처방·비처방 약, 비타민, 한약을 최근 6개월까지 기록하고, 환자와 가족에게 여러 번 묻습니다(EASL ALF 2017 p.7). 비 paracetamol DILI에 의한 ALF는 배제 진단입니다(근거 III, 권고 2) (EASL ALF 2017 p.8).
- HEV: 토착형 HEV 감염은 DILI로 오진될 수 있습니다(EASL ALF 2017 p.7).
- Paracetamol: 입원 시 모든 환자에서 독성 선별검사와 paracetamol 농도를 측정하고, 이미 응고장애와 효소 상승이 있으면 NAC를 줍니다(근거 II-2, 권고 1) (EASL ALF 2017 p.8). [[acetaminophen]]
- 바이러스: 원인 바이러스와 보조 인자(co-factor) 선별을 항상 시행합니다(근거 II-2, 권고 1) (EASL ALF 2017 p.8). 원인이 불분명하면 CMV와 EBV 핵산 검사를 합니다(EASL ALF 2017 p.7). [[viral-hepatitis-testing]]
- 이차성 원인: 일차 간 원인이 아닌 효소 상승·담즙정체·응고장애 환자에서는 패혈증, 말라리아, 렙토스피라증, 리케차, 갑상선 질환, Still병, 혈구탐식 증후군을 선별합니다(EASL ALF 2017 p.9).

Table 8의 입원 시 원인 검사(EASL ALF 2017 p.10):
- 소변 독성 선별, 혈청 paracetamol 농도
- HBsAg, anti-HBc IgM(HBV DNA), HBV 양성이면 delta, anti-HAV IgM, anti-HEV IgM, anti-HSV IgM, anti-VZV IgM, CMV·HSV·EBV·parvovirus·VZV PCR
- 자가면역 표지: ANA, ASMA, anti-soluble liver antigen, 글로불린, ANCA, HLA typing
- 중증도: PT, INR 또는 factor V, 섬유소원, LDH와 포합·비포합 빌리루빈, CK, 동맥혈 가스와 젖산, 동맥 암모니아

## 바이러스별 요점

- HBV는 중증 ALI와 ALF의 가장 흔한 바이러스 원인이며 급성 B형간염의 4% 미만이 ALF로 진행하고, 면역억제 중 재활성화는 새 감염보다 사망률이 높습니다(EASL ALF 2017 p.7).
- 급성 HAV의 1% 미만이 ALF로 진행합니다(EASL ALF 2017 p.7).
- HSV-1·2와 VZV는 드문 원인이며, 피부 병변이 없어도 배제할 수 없습니다(EASL ALF 2017 p.7).

## ICU 원인 판단에 쓰는 법

(아래는 원문에서 도출한 적용 방법이며 원문의 직접 권고가 아닙니다.)
- ICU에서 쇼크·저산소에 동반된 효소 급상승과 응고장애는 EASL 분류상 일차 ALF가 아니라 이차성 간손상 또는 HH로 보는 것이 원문 정의에 맞습니다(EASL ALF 2017 p.1, p.5-6).
- AST >10,000 IU/L와 정상 빌리루빈은 허혈과 paracetamol에 공통되므로, 둘을 가르려면 혈역학 경과와 paracetamol 농도·병력이 필요합니다(EASL ALF 2017 p.5-6).
- Coombs 음성 용혈성 빈혈과 높은 빌리루빈 대 ALP 비가 있으면 용혈 원인으로 Wilson병을 고려할 근거가 됩니다(EASL ALF 2017 p.9). [[isolated-hyperbilirubinemia]]

## 근거 공백

- ALI·ALF 정의의 아미노전이효소 배수는 "2-3배"로만 기술되고, ULN 기준인지와 측정 횟수는 정의되지 않습니다(EASL ALF 2017 p.1).
- 이차성 간손상(패혈증 등)의 진단 기준이나 수치 기준은 제시하지 않습니다(EASL ALF 2017 p.1, p.9).
