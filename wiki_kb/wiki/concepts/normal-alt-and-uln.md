# 정상 ALT와 ULN, 상승 정도 분류

## 진정한 정상 ALT
- 간질환 위험인자가 없는 인구를 전향적으로 조사했을 때 건강인 정상 ALT는 남성 29-33 IU/l, 여성 19-25 IU/l이며, 이보다 높으면 의사가 평가해야 합니다 (ACG 2017 p.4).
- 요약 부분에서도 정상 ALT는 남성 <29-33 IU/l, 여성 <19-25 IU/l이어야 한다고 다시 적습니다 (ACG 2017 p.16).
- 이 지침은 ALT와 간 관련 사망률의 상관 문헌을 근거로 "정상" ALT를 정의했지만 임상 판단이 여전히 가장 중요하다고 합니다 (ACG 2017 p.6).
- 간질환 징후나 증상이 있으면 간 검사가 정상이어도 평가를 시작해야 합니다 (ACG 2017 p.6).

## ULN 개념
- 정상 검사값은 대개 건강 인구의 평균 ±2 표준편차로 정하며, 이 정의상 인구의 2.5%는 ULN을 넘습니다 (ACG 2017 p.4).
- ALP와 빌리루빈은 검사실 사이 정상범위 재현에 문제가 보고되지 않아 지역 검사실 ULN을 써도 되지만, ALT·AST는 건강 대조군 정의가 달라 정상범위 설정이 어렵습니다 (ACG 2017 p.4).
- NASH Clinical Research Network의 지역 검사실 ALT ULN은 남성 35-79 IU/l, 여성 31-55 IU/l로 크게 달랐습니다 (ACG 2017 p.4).
- 한 주(state)의 67개 검사실은 ALT ULN으로 31-72 U/l을 썼고, ULN 정의 방법도 제각각이었습니다 (ACG 2017 p.4).
- 다만 검사실 사이 ALT 측정값 자체의 차이는 유의하지 않다고 보고되었습니다 (ACG 2017 p.4).
- ALT는 BMI와 선형 관계가 있고 남성이 여성보다 높습니다 (ACG 2017 p.4).
- 정상 ALT가 의미 있는 간질환을 배제하지는 못합니다 (ACG 2017 p.4).
- 이전 지침들이 ALT ULN의 배수(2X, 3X ULN 등)로 결정을 내리면서 ALT 수치 자체를 정하지 않아 진료 편차가 생겼다고 지적합니다 (ACG 2017 p.6).

## ALT·AST와 사망률
- 독일 보고에서 AST >18 U/l은 전체 사망 위험이 3배였습니다 (ACG 2017 p.4, p.5).
- 한국 연구에서 AST 또는 ALT <20 IU/l인 남성에 비해 30-39 IU/l 군은 간 관련 사망 상대위험이 AST 8배, ALT 9.5배였습니다 (ACG 2017 p.5).
- Olmsted County 연구에서 표준화 사망비는 정상 ALT 0.95, 1-2X ULN 1.32, >2X ULN 1.78이었습니다 (ACG 2017 p.5).
- NHANES 분석에서 ALT 상승(ULN 남성 30, 여성 19 U/l)은 간 관련 사망 11.2배, 당뇨 관련 사망 3.3배 증가와 연관되었습니다 (ACG 2017 p.5).
- 저자들은 여러 인구에서 ALT 남성 >33 IU/l, 여성 >25 IU/l에서 간 관련 사망이 늘었다는 점을 근거로 ALT 표준화가 필요하다고 봅니다 (ACG 2017 p.5).
- ULN을 낮추면 NHANES 기준 남성 36%, 여성 28%가 ALT 상승으로 분류되며, 비용·불필요한 검사 증가를 들어 반대하는 의견도 소개합니다 (ACG 2017 p.5).

## 상승 정도 분류 (원문 정의 그대로)
| 분류 | 정의 | 쪽 |
|---|---|---|
| 경계(borderline) | AST 그리고/또는 ALT <2X ULN | p.11, p.12 |
| 경도(mild) | 2-5X ULN | p.12 |
| 중등도(moderate) | 5-15X ULN | p.12 |
| 중증(severe) | >15X ULN | p.12 |
| 대량(massive) | >10,000 IU/l | p.12 |

- 경계·경도 상승은 Table 4의 여러 간·비간 원인에서 보이고, 중등도 상승은 경도·중증 목록과 겹칩니다 (ACG 2017 p.12).
- 중등도, 중증, 대량 상승은 즉시 평가가 필요합니다 (ACG 2017 p.12).
- 대량 상승(>10,000 U/l)은 대체로 shock liver/ischemic hepatopathy 또는 약물·독성 간염에서만 보입니다 (ACG 2017 p.12). [[hypoxic-hepatitis]]
- 급성 간부전(fulminant hepatic failure)은 ALT 수치와 무관하게 즉시 평가해야 합니다 (ACG 2017 p.12).

## ICU 원인 판단에 쓰는 법
(아래는 원문 내용을 ICU 상황에 적용한 파생 해석입니다.)
- 이 위키의 진입 기준(≥2×ULN)은 원문 분류로 경도(2-5X) 이상에 해당하므로, 상승 배수를 원문 범주로 옮겨 적용할 알고리즘(Figure 1, 2, 3)을 고릅니다 (ACG 2017 p.10, p.11, p.12).
- 원문은 지역 검사실 ULN이 크게 다를 수 있다고 하므로, 배수를 계산할 때 어떤 ULN을 썼는지 명시하는 것이 판단 일관성에 필요합니다 (ACG 2017 p.4).
- 중증(>15X) 또는 대량(>10,000 IU/l) 상승은 허혈성 간병증(shock liver)과 약물·독성 간염을 우선 고려하는 근거가 됩니다 (ACG 2017 p.2, p.12).
- 횡문근융해와 열사병도 중증·대량 AST 상승을 일으킬 수 있으므로, 대량 상승을 곧바로 간 원인으로 단정하지 않습니다 (ACG 2017 p.12).

## 근거 공백
- 원문의 "진정한 정상 ALT"는 외래·건강 인구 기반이며 ICU 환자의 기준치를 다루지 않습니다.
- ALP와 빌리루빈의 배수별 분류(경도·중등도 등)는 정의하지 않고, ALT/AST에 대해서만 정의합니다.
- 상승 배수를 지역 검사실 ULN으로 계산할지 원문의 정상 ALT(29-33/19-25 IU/l)로 계산할지 명시하지 않습니다.
- 상승 정도의 시간 경과(얼마나 빨리 오르고 떨어지는지)를 원인 판정에 쓰는 기준은 없습니다.
