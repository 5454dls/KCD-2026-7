# 저산소성 간염과 다른 급성 간세포 손상의 감별

## 감별 범위
원문은 혈청 aminotransferase >10×ULN의 간 감별 진단으로 다섯 가지를 듭니다(HH review p.4, Table 2).
- 저산소성 간염(hypoxic hepatitis) (HH review p.4)
- 급성 바이러스 간염(acute viral hepatitis) (HH review p.4)
- 독소·약물 유발 간손상(toxin- or drug-induced liver injury) (HH review p.4)
- 자가면역 간염(autoimmune hepatitis) (HH review p.4)
- 간 외상(liver trauma) (HH review p.4)

원문은 대량·급속 효소 상승의 감별은 제한적이고 HH가 주요 원인 중 하나라고 서술합니다(HH review p.3).
- Henrion 2007은 고령·전신 상태 불량 환자에서 특히 HSV 감염과 acetaminophen 중독을 배제하라고 강조합니다(Henrion 2007 p.1). [[acetaminophen]]

## 비교표 (원문이 직접 비교한 항목만)
| 항목 | 저산소성 간염 (HH) | 바이러스 간염 | 약물·독소 간손상 (DILI) | 자가면역 간염, 간 외상 |
|---|---|---|---|---|
| 진단에서의 위치 | 세 기준을 만족하면 진단, 생검 불필요 (HH review p.3) | HH 진단 기준 3번에서 반드시 배제할 대상 (HH review p.3) | HH 진단 기준 3번에서 반드시 배제할 대상 (HH review p.3) | >10×ULN 감별 목록에만 등장 (HH review p.4) |
| 임상 배경 | 심장, 순환, 호흡 부전 (HH review p.3) | 원문 서술 없음 | 원문 서술 없음 | 원문 서술 없음 |
| LDH | 극적 상승, HH를 가리킬 수 있음 (HH review p.2) | HH보다 LDH 정점이 대체로 낮음 (HH review p.4) | 원문 서술 없음 | 원문 서술 없음 |
| 효소 경과 | 흔히 24시간 내 정점, 24-72시간 뒤 정점의 절반 가까이, 1-2주 내 정상화 (HH review p.2-3) | 원문 서술 없음 | 원문 서술 없음 | 원문 서술 없음 |
| 손상 패턴 | 간세포형, 큰 ALP 상승은 비전형적 (HH review p.4) | 원문 서술 없음 | 원문 서술 없음 | 원문 서술 없음 |
| 영상 | 수동 울혈에 의한 IVC·간정맥 확장이 HH 시사(검증 안 됨), CT·MRI는 다른 원인 배제에 도움 (HH review p.4) | 원문 서술 없음 | 원문 서술 없음 | 원문 서술 없음 |
| 생검 | 진단 불분명(예: <20×ULN) 시 centrilobular necrosis 확인 (HH review p.3) | 원문 서술 없음 | 원문 서술 없음 | 원문 서술 없음 |
| 효소 크기 예 | 정점 중앙값 AST 2,510, ALT 1,366 U/L, AST 우세 (Fuhrmann 2011 p.4) | 원문 서술 없음 | acetaminophen 간염은 HH와 생화학 양상이 비슷 (Henrion 2007 p.2) | 원문 서술 없음 |
| 오인 경로 | 숨은 심부전(이뇨제 치료 중)에서 우상복부 통증으로 DILI·담도 질환으로 오인 (Henrion 2007 p.2) | HSV는 반드시 배제 (Henrion 2007 p.1) | acetaminophen 농도 측정 유용 (Henrion 2007 p.2) | 원문 서술 없음 |
| 초음파 소견 (Henrion) | 대부분 간정맥 확장(수동 울혈) (Henrion 2007 p.1) | 원문 서술 없음 | 원문 서술 없음 | 원문 서술 없음 |

## 해석
- 이 원문이 HH와 다른 원인을 직접 비교하는 검사 소견은 LDH 정점(바이러스 간염과 비교)과 간세포형 패턴(ALP 상승이 크면 비전형적) 두 가지뿐입니다(HH review p.2, p.4).
- 약물, 자가면역, 외상에 대해서는 감별 목록과 배제 필요성만 제시하고 감별 소견은 제시하지 않습니다(HH review p.3-4).
- 다른 원인의 구체적 검사는 [[viral-hepatitis-testing]], [[dili-diagnosis-and-causality]], [[hepatocellular-injury-workup]]에서 다룹니다.

## 근거 공백
- ALT/LDH 비 등 정량 판별 기준은 이 원문에 없고, Henrion 2007, Fuhrmann 2011, Waseem NIS 2018에도 없습니다.
- acetaminophen 간염과 HH를 생화학으로 구별하는 기준은 없고, 병력과 혈중 농도에 의존합니다(Henrion 2007 p.2).
- DILI, 자가면역 간염, 간 외상과 HH를 구별하는 검사 소견이나 시간 경과는 서술되지 않습니다.
- 바이러스 간염의 효소 경과(정점 시점, 하강 속도)는 서술되지 않아 시간 경과로 직접 비교할 수 없습니다.
