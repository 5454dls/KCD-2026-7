# 울혈성 간병증: 울혈과 섬유화의 구별 (Lemmer, VanWagner, Ganger 2017)

Northwestern University 저자들의 짧은 리뷰로, Clinical Liver Disease 10권 6호(2017년 12월) 139-143쪽에 실렸습니다(Lemmer 2017 p.1). 2017년 8월 6일 접수, 10월 28일 수락되었습니다(Lemmer 2017 p.1). 파일 이름은 2018이지만 인쇄된 권호와 저작권 표기는 2017년입니다(Lemmer 2017 p.1). DOI(10.1002/cld.676)는 본문에 인쇄되어 있지 않고 PDF 메타데이터에서 확인했습니다.

주된 모델은 단심실 선천 심질환으로 Fontan 수술을 받은 뒤 수십 년간 간 울혈이 지속되는 Fontan 관련 간질환(FALD)입니다(Lemmer 2017 p.1). Table 1의 평균값 출처(참고문헌 5, 6, 8)도 Fontan 코호트입니다(Lemmer 2017 p.3, p.5). 따라서 ICU의 급성 울혈 상황에 직접 적용한 자료가 아닙니다.

## 요점

- 울혈성 간병증은 우심부전으로 간정맥압이 만성적으로 높아져 생기며, 높은 심장 압력이 간 중심정맥으로 전달되어 굴모양혈관 확장, 간동맥 혈류 감소, 동맥 산소포화도 감소를 거쳐 가교 섬유화, 간경변, 간세포암까지 이어질 수 있습니다(Lemmer 2017 p.1).
- 바이러스·자가면역·알코올성·비알코올성 지방간염 같은 염증성 간병증과 달리 비염증성 과정이며, 초기 증상은 합성 기능이 보존된 상태에서 문맥압 항진으로 나타납니다(Lemmer 2017 p.1).
- AST, ALT, ALP, 빌리루빈, PT, 알부민, FibroSURE, hyaluronic acid 대부분은 말기 직전까지 정상에 가깝고 생검 섬유화 등급과 상관하지 않아 진단·병기 결정에 거의 쓸모가 없습니다(Lemmer 2017 p.1-2).
- 낮은 혈소판과 높은 GGT는 문맥압 항진 정도와 상관하지만 섬유화와는 상관하지 않아, 간 기능보다 심장 기능과 우심 압력의 표지로 봅니다(Lemmer 2017 p.2). [[gamma-glutamyl-transferase]]
- BNP는 한 리뷰에서 생검 섬유화 등급과 상관하지 않았고, 울혈성 간병증에서 BNP와 임상 결과의 관계는 따로 연구되지 않았습니다(Lemmer 2017 p.2).
- MELD는 INR이 말기에만 오르고 많은 환자가 항응고제를 쓰기 때문에 효과가 없어 보이며, INR을 뺀 MELD-XI가 간 대상부전과 사망을 예측한다는 연구가 여럿 있습니다(Lemmer 2017 p.2).
- 요약은 MELD-XI를 울혈성 간질환에서 임상 결과를 예측하는 유일한 검증된 혈청 기반 검사로, 비침습 간 경직도 검사는 모든 환자에서 높게 나와 울혈과 섬유화를 구별하지 못한다고 정리합니다(Lemmer 2017 p.4).
- 선별·관리를 이끌 근거 기반 지침은 현재 없다고 명시합니다(Lemmer 2017 p.4).

## ICU 원인 판단과의 관계

- 이 원문은 만성 울혈을 다루며, 급성 울혈에서 간 검사 이상을 판단하는 수치 기준, NT-proBNP 기준, 중심정맥압 같은 혈역학 임계값을 제시하지 않습니다(Lemmer 2017 p.1-4).
- 초음파의 간비대와 하대정맥·간정맥 확장을 전형 소견으로 들고 있어(Lemmer 2017 p.2-3), HH 리뷰의 초음파 소견과 같은 방향입니다. [[hypoxic-hepatitis]]

## 한계 (원문이 밝힌 것)

- 혈청·영상 검사 중 생검 섬유화 병기를 재현성 있게 예측하는 검증된 검사는 적고, 단일 생검도 간 전체의 섬유화 부담을 정확히 보여주지 못할 수 있습니다(Lemmer 2017 p.4).
- 울혈성 간병증에 표준화된 섬유화 병기 체계가 없고, 심장이식 전 생검 결과는 이식 후 간 결과를 예측하지 못했습니다(Lemmer 2017 p.4).
- 새로운 바이오마커 개발이 필요하다고 결론짓습니다(Lemmer 2017 p.4).
