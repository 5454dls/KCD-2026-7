# EASL 급성(전격성) 간부전 진료 지침 (J Hepatol 2017)

유럽간학회(EASL)의 급성 간부전(acute liver failure, ALF) 임상 진료 지침입니다(EASL ALF 2017 p.1). 패널 의장은 Julia Wendon이며, 2016년 12월 7일 접수·수락되어 Journal of Hepatology 2017;66:1047-1081에 실렸습니다(EASL ALF 2017 p.1). DOI는 참고문헌 쪽에 인쇄되어 있습니다(EASL ALF 2017 p.28). 근거와 권고는 GRADE 체계로 등급을 매겼고(근거 I-III, 권고 1 strong, 2 weaker) (EASL ALF 2017 p.1-2), 35쪽 중 이 위키는 정의, 원인 평가, 예후 기준을 중심으로 요약합니다. 이식 수술·장기별 지지 요법의 세부는 생략했습니다.

## 요점

- ALF는 기저 만성 간질환이 없는 사람에서 간 혈액 검사의 급성 이상, 간 원인의 응고장애(패혈증의 응고 이상과 구별), 간성 뇌병증(HE)에 의한 의식 변화가 함께 있는 드문 증후군입니다(EASL ALF 2017 p.1).
- 응고장애는 있지만 의식 변화가 없으면 급성 간손상(acute liver injury, ALI)으로 정의합니다(EASL ALF 2017 p.1).
- 일차 간 손상이 없는 전신 질환에서 응고장애, 아미노전이효소 상승, 빌리루빈 이상, 의식 변화가 보이면 ALF가 아니라 이차성 간손상(secondary liver injury)으로 보고 기저 질환 치료에 집중합니다(EASL ALF 2017 p.1). 원문 인용: "if there is no primary liver insult, these patients should be considered to have a secondary liver injury and not ALF"(EASL ALF 2017 p.1).
- 중증 ALI는 아미노전이효소 2-3배 상승과 간기능 저하(황달, 응고장애)로 시작하며(EASL ALF 2017 p.1), 권고문은 아미노전이효소 상승, 황달, INR >1.5를 표지로 듭니다(EASL ALF 2017 p.3).
- 유럽에서 가장 흔한 ALF 원인은 이제 DILI이고, 지역에 따라 paracetamol 과다복용 또는 비 paracetamol 약물 독성이 우세합니다(EASL ALF 2017 p.3).
- 저산소성 간염(hypoxic hepatitis)은 이차성 ALF이며 응급 간이식 적응이 아닙니다(EASL ALF 2017 p.5-6). [[hypoxic-hepatitis]]
- 이식 고려 기준으로 Clichy 또는 King's College 기준을 권고합니다(근거 II-2, 권고 1) (EASL ALF 2017 p.23). [[kings-college-criteria]]

## ICU 관련 언급 (원문에서 직접 찾은 것)

- 급성 허혈성 손상은 고령, 심혈관 질환, 심한 울혈성 심질환에서 위험이 높고, 우심 기능 이상과 간 울혈이 있는 상태에 저산소나 저혈압이 겹쳐 흔히 생기며, 저혈압·저산소 기록이 없어도 배제할 수 없습니다(EASL ALF 2017 p.5).
- 중환자실 연구에서 저산소성 간염 유병률은 1.2-11%이고, 호흡부전, 심부전, 패혈성 쇼크·저혈압의 세 원인 아군으로 나뉩니다(EASL ALF 2017 p.5).
- 허혈성 손상에서 AST는 흔히 10,000 IU/L를 넘고 ALT의 두 배 이상이며, 첫 검사에서 빌리루빈이 정상인 경우가 많습니다(EASL ALF 2017 p.5).
- Table 6은 급성 허혈성 손상의 특징으로 아미노전이효소의 현저한 상승, LDH와 크레아티닌 증가, 혈역학 안정 후 빠른 정상화, 심한 울혈성 심질환 또는 호흡기 질환을 듭니다(EASL ALF 2017 p.6). [[lactate-dehydrogenase]]
- 서방형 niacin, cocaine, methamphetamine은 저관류로 간 허혈을 일으킬 수 있습니다(EASL ALF 2017 p.7).
- 이차성 ALF·ALI의 선별 대상에 패혈증, 말라리아, 렙토스피라증, 리케차, 갑상선 질환, Still병, 혈구탐식 증후군이 있습니다(EASL ALF 2017 p.9).
- 저산소성 간염 일부는 좌우 심기능 이상을 동반하므로 간정맥 배출을 위해 우심 압력을 최소화하고, 관상동맥 관류를 위한 MAP는 norepinephrine 같은 승압제로 유지하며, 강심제(inotrope) 고려가 필요합니다(EASL ALF 2017 p.13-14). [[norepinephrine]]
- ALF의 첫 승압제는 norepinephrine 0.05 μg/kg/min에서 시작하고, 요구량이 0.2-0.3 μg/kg/min을 넘으면 저용량 vasopressin(1-2 units/hour) 추가를 고려합니다(EASL ALF 2017 p.13). [[vasopressin]]
- 혈압 목표는 문헌에서 정의되지 않았다고 권고문에 적혀 있습니다(근거 III, 권고 2) (EASL ALF 2017 p.14).
- ALF에서 세균 감염은 60-80%에서 확인되고, 장기 중환자 치료가 필요한 환자의 약 3분의 1에서 진균 감염이 생깁니다(EASL ALF 2017 p.18).

## 한계 (원문이 밝힌 것)

- EU 내 ALF의 실제 발생률과 부담은 알 수 없습니다(EASL ALF 2017 p.3).
- INR은 표준화되어 있지 않고 warfarin 감시용으로 만들어졌으며, ALF 정의의 INR·PT 기준은 재검토가 필요합니다(EASL ALF 2017 p.2-3).
- 이식 선택 기준의 성능 자료는 부족하고 어떤 체계도 보편적으로 채택되지 않았으며, 수십 년 전 환자로 만든 예후 체계는 현재 치료 수준에 맞지 않을 수 있습니다(EASL ALF 2017 p.23).
- 새 예후 표지자 연구는 작고 검증이 부족해 일상 사용을 권고할 수 없습니다(EASL ALF 2017 p.23).
