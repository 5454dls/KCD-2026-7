# RUCAM

- Roussel-Uclaf Causality Assessment Method로, Council for International Organizations of Medical Sciences(CIOMS) scale이라고도 하며 1993년에 처음 발표되었습니다(AASLD DILI p.12).
- 원판은 -10~+14점이고 점수를 5개 가능성 범주로 묶으며, 간세포형과 담즙정체·혼합형을 나누어 평가합니다(AASLD DILI p.12).
- 2016년 개정판(updated RUCAM)은 -9~+14점이며 5개 범주는 같습니다(AASLD DILI p.12).

## 개정 RUCAM 항목 점수 (Table 5)

| 항목 | 점수 |
|---|---|
| 약물 시작부터 손상 발현까지 | +1~+2 |
| 약물 중단부터 손상 발현까지 | +1 (앞 항목과 둘 중 하나만 계산) |
| Dechallenge | 간세포형 -2~+3, 담즙정체/혼합형 0~+2 |
| 경쟁 원인 | -3~+2 |
| 재투여 | 0~+3 |
| 약물/HDS 간독성 기록 | 0~+2 |
| 위험 인자 | 0~+1 |
| 병용 약물 | -3~0 |
| 범주 | definite ≥ 9, probable 6-8, possible 3-5, unlikely 1-2, excluded ≤ 0 |

(AASLD DILI p.13)

## 한계

- 영역 가중치가 근거 기반·통계적 가중이 아니라 재투여 사례 집합으로 만들어졌습니다(AASLD DILI p.14).
- 급성 HCV, HEV 검사를 요구하지 않고, 위험 인자 포함을 뒷받침하는 자료가 적습니다(AASLD DILI p.14).
- 개정판은 R 값으로 층화하고, 대체 진단 탐색을 넓히고, 재투여 기준을 명시하지만, 나이·알코올 위험 인자를 모든 사례에 유지합니다(AASLD DILI p.14).
- 개정판은 만성 간질환 환자용이 아닙니다(AASLD DILI p.14).
- Guidance statement 27은 개정판이 사용 지침과 진단 평가를 개선했지만 가치가 불분명한 나이, 알코올, 임신 위험 인자를 유지한다고 평가합니다(AASLD DILI p.14).
- 전문가 의견 접근은 RUCAM만큼 유용하다고 보고되었습니다(AASLD DILI p.14).
